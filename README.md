# I Gede Deva Dharma

I'm a student and independent builder based in Indonesia. I build web
products and automation for game communities and small businesses —
stores, license systems, and bots that do the repetitive work.

## Products

- **SKYGTPS** — Game-item store with Midtrans payments, an admin panel,
  and automatic delivery. Live at
  [gtshop.skygtps.store](https://gtshop.skygtps.store). Built with
  Next.js, React, and Tailwind.
- **SkyProxy** — Growtopia proxy with a license system, Discord bot, and
  web dashboard. Live at [skygtproxy.pages.dev](https://skygtproxy.pages.dev).
  Built with Node.js.
- **Telegram automation** — Bots and a Mini App for stock checks and sales
  recording, with browser automation behind them. Built with Python and
  Playwright.
