## About Me

I'm a student and independent builder based in Indonesia. I build web
products and automation for game communities and small businesses —
stores, license systems, and bots that do the repetitive work.

- 🔭 **Currently:** running a live game-item store, a proxy product
  with its own license system, and Telegram automation for daily
  operations.
- 🌱 **Focus:** full-stack web apps, payment integration, browser
  automation, and Lua scripting for game servers.
- ⚙️ **Approach:** ship real products used by real people, automate
  the boring parts, and document every repo so anyone can run it.

## How I Work

- **Real products first.** Everything in Live Projects is deployed and
  used, not a mockup.
- **Automation over repetition.** If a task repeats daily, it gets a
  bot, a script, or a scheduled job.
- **Docs in every repo.** Each project has its own README with setup
  and usage instructions, so anyone can run it from scratch.
